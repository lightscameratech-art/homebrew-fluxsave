# FluxSave Homebrew Tap

Install FluxSave on an Apple Silicon Mac:

```sh
brew tap lightscameratech-art/fluxsave
brew install --cask fluxsave
```

Upgrade to the newest published release:

```sh
brew update
brew upgrade --cask fluxsave
```

FluxSave downloads only media that you own or have permission to save. Private and DRM-protected content is unsupported unless the platform provides authorized access.
